How book issuing works

  1. Find a book in the catalog or search.
  2. If copies are available, click Request issue. Your request waits for librarian approval.
  3. After approval, the book is issued with a due date. You can see it under My issues.
  4. Return the book from Return a book before the due date to avoid fines (₹{{ FINE_PER_DAY }}/day).
  5. If no copies are free, use Join waitlist — we email you when a copy is returned.
